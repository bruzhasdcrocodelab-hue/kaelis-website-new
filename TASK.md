### 2.3. Новый блок Ask a Question

Вместо текущего `AskQuestionStep` из `src/components/categories-page/CategoryTopBlock/CategoryTopBlock.tsx` на `CategoryPageView` реализовать самостоятельный блок по макету.

**Критически важно:** текущий `CategoryTopBlock` со всеми его шагами не удалять и не изменять — он используется на главной странице и должен полностью сохранить существующую логику.

Новый блок реализовать отдельно, используя существующую бизнес-логику отправки вопросов и генерации раскладов через backend/API.

Требования:

- Для фона использовать `public/images/backgrounds/pattern-categories-top-block-2.svg`.
- На десктопе использовать текущий `src/components/categories-page/TriggerButton/TriggerButton.tsx`.
- На мобильной версии добавить `triggerMobile` по аналогии с реализацией в `CategoryTopBlock`, органично разместив его внутри нового блока.
- Поле ввода, кнопка `Get My Reading` и три примера вопросов из `Try a question` должны соответствовать макету.

**Отправка пользовательского вопроса:**

- После отправки блок остаётся на месте, не меняет структуру, а поле ввода очищается.
- Если уже запущен расклад или имеется результат предыдущего расклада, перед новым запросом показать существующую `src/components/global/ConfirmationModal/ConfirmationModal.tsx`.
- При отказе пользователь остаётся на текущем раскладе без изменений.
- При подтверждении предыдущий процесс сбрасывается / прерывается, после чего запускается новый запрос.
- Использовать существующую логику работы с API, не создавая дублирующую реализацию генерации раскладов.

**Примеры вопросов:**

- Получать через API `tarot.questions.index`: https://stagtest.kaelisai.com/docs/api/#/operations/tarot.questions.index
- Запрашивать вопросы для конкретного расклада.
- Выводить три вопроса (первые три или случайные), сразу получая переводы EN/RU/UA.
- При нажатии на пример сразу запускать расклад с этим вопросом.
- При этом поле ручного ввода не очищать и не изменять, блок Ask a Question не должен исчезать или переключаться.
- При наличии активного процесса или готового результата использовать ту же логику подтверждения, что и при ручной отправке.

Для запуска нового расклада из примера использовать те же механизмы сброса и отправки, что и для ручного вопроса.

**Шаги ChooseCardsStep и RevealCardsStep:**
После отправки вопроса из блока "Ask a Question" (расклад начат) в hero анимированно появляется блок CategoryTopBlock сразу на втором шаге (ChooseCardsStep) согласно скринам:

После завершения шага ChooseCardsStep переходим на шаг RevealCardsStep в этом же CategoryTopBlock, как это уже есть сейчас. 
Их текущая логика, вёрстка и функционал по сути не меняется, они встраиваются в страницу (под остальным контентом hero - как на скринах / макетах), как есть.
